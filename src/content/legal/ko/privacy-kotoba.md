## 2. 수집하는 개인정보 항목

회사는 서비스 제공을 위하여 필요한 최소한의 개인정보만을 수집합니다. 본 항목에 명시되지 아니한 정보는 수집하지 아니합니다.

### 2.1 회원가입 및 로그인 시 수집하는 항목

| 인증 수단 | 수집 항목 |
|---|---|
| 이메일/비밀번호 | 이메일 주소, 비밀번호(해시값), 표시 이름(선택) |
| Google 로그인(OAuth 2.0) | 이메일 주소, Google 계정 식별자(`sub`), 표시 이름 |
| Apple 로그인 | 이메일 주소(또는 Apple "이메일 가리기(Hide My Email)"로 발급된 익명 릴레이 이메일), Apple 사용자 식별자(`user identifier`), 표시 이름(최초 로그인 시에 한함) |

비밀번호 원본은 저장하지 아니하며, Supabase Auth가 제공하는 단방향 해시 알고리즘으로만 보관합니다. Apple 로그인 이용자가 "이메일 가리기" 기능을 사용한 경우, 회사는 Apple이 발급한 익명 릴레이 이메일(`@privaterelay.appleid.com`)만을 수신·보관하며 이용자의 실제 이메일은 알 수 없습니다.

### 2.2 서비스 이용 과정에서 자동으로 수집되는 항목

- 학습 활동 로그: 학습 세션 시간, 정답률, 학습한 단어 ID, 연속 학습일(스트릭), 누적 경험치(XP), 사용자 레벨
- 일일 사용량 카운터(전체 기능 및 AI 기능 별도 집계)
- 결제 만료일(`subscription_expires_at`) 
- 게이미피케이션 데이터: 보유 코인 수량, 보유 아이템, 달성 도전과제, 코인 거래 이력
- 사용자 신고·문의 내역(고객지원 티켓, 단어 신고 내역)

### 2.3 AI 기능 이용 시 처리되는 항목

이용자가 AI 튜터, 문법 교정, 학습 플랜 생성, 예문 생성 기능을 이용하는 경우 다음의 정보가 처리됩니다.

- 이용자가 직접 입력한 일본어·한국어 문장 또는 단어
- 문법 교정을 위해 입력한 텍스트
- 학습 플랜 생성을 위한 학습 통계 요약(예: 현재 JLPT 레벨, 목표 시험일, 학습 진척도)
- 예문 생성을 위해 선택한 단어와 그 뜻

회사는 이메일, 이름, OAuth 식별자 등 이용자를 직접 식별할 수 있는 정보를 AI 처리 위탁자(Anthropic, PBC)에게 전송하지 아니합니다.

### 2.4 단말기 내 로컬 저장(AsyncStorage) 항목

서비스는 다음의 데이터를 이용자 단말기 내부 저장소(AsyncStorage)에만 저장합니다. 이 데이터는 서버로 전송되지 아니하며, 앱 삭제 시 함께 삭제됩니다.

| 키 | 용도 |
|---|---|
| `ai_chat_messages` | 최근 AI 채팅 메시지 30개(단말기 내 임시 보관) |
| `ai_chat_level` | 사용자가 선택한 AI 채팅 난이도 |
| `ai_study_plan` | AI가 생성한 학습 플랜 캐시 |
| `jlpt_target_date` | 이용자가 설정한 JLPT 목표 시험일 |
| `target_jlpt_level` | 이용자가 설정한 목표 JLPT 레벨 |
| `saved_email` | 로그인 화면 자동 채움용 이메일(이용자 선택 시) |
| `ADMIN_AUTH_KEY` | 운영자 전용 인증 키(일반 이용자 미사용) |

### 2.5 수집하지 않는 정보

회사는 본 방침에 명시되지 아니한 다음의 정보를 수집하지 아니합니다.

- 주민등록번호, 외국인등록번호 등 고유식별정보
- 위치정보(GPS, Wi-Fi 기반 위치)
- 주소록·연락처, 사진·미디어 라이브러리, 마이크, 카메라
- 광고 식별자(IDFA, GAID), 행동 분석을 위한 제3자 SDK 데이터
- 별도의 분석/크래시 리포팅 SDK(현재 미사용)

## 4. 개인정보의 보유 및 이용 기간

회사는 원칙적으로 이용자의 개인정보를 회원 가입일부터 회원 탈퇴 시까지 보유·이용합니다. 회원 탈퇴 요청 시 다음의 절차에 따라 처리됩니다.

| 구분 | 보유 기간 |
|---|---|
| 회원 정보(이메일, OAuth 식별자, 표시 이름) | 회원 탈퇴 시 즉시 파기 (제4.1항의 법령상 보존 의무에 해당하는 경우 분리 보관) |
| 학습 기록(세션, 단어 통계, 코인 거래 등) | 회원 정보와 동일 |
| AI 입력 텍스트(서버 측) | 처리 후 즉시 폐기. 단, Supabase Edge Function `ai-proxy` 로그에 디버깅 목적으로 일시 기록될 수 있으며 최대 30일 이내 자동 삭제 |
| AI 입력 텍스트(Anthropic 측) | Anthropic, PBC의 자체 정책에 따름(아래 제5항 참고) |
| 단말기 내 AsyncStorage 데이터 | 이용자가 앱을 삭제하거나 직접 초기화할 때까지 |

### 4.1 법령상 의무 보존

회사는 위탁계약 체결 시 「개인정보 보호법」 제26조에 따라 위탁업무 수행 목적 외 개인정보 처리 금지, 기술적·관리적 보호조치, 재위탁 제한, 수탁자에 대한 관리·감독, 손해배상 등 책임에 관한 사항을 계약서 등 문서에 명시하고, 수탁자가 개인정보를 안전하게 처리하는지를 감독하고 있습니다.

### 8.1 EEA·영국 거주 이용자의 권리(GDPR 보충 조항)

유럽경제지역(EEA), 영국, 스위스에 거주하는 이용자는 GDPR 및 그에 상응하는 법령에 따라 다음의 권리를 추가로 가집니다.

- 처리 거부권(Right to object), 동의 철회권(Right to withdraw consent)
- 자동화된 의사결정에 관한 권리
- 감독기관(예: 거주 회원국의 데이터 보호 감독기관)에 대한 진정 제기권

처리의 법적 근거는 (i) 서비스 계약 이행(GDPR 제6(1)(b)조), (ii) 이용자의 동의(제6(1)(a)조), (iii) 회사의 정당한 이익(제6(1)(f)조)입니다. 미국·일본으로의 이전에 대해서는 표준계약조항(SCC) 또는 그에 상응하는 보호조치를 적용합니다.
