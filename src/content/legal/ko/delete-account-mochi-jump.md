# 계정 및 데이터 삭제 — Mochi Jump (모치 점프)

> 최종 수정: 2026-05-13

Mochi Jump의 계정과 관련 데이터의 삭제를 요청하실 수 있습니다.

## 1. 앱 내에서 직접 삭제 (권장, 즉시)

앱이 설치되어 있고 로그인되어 있다면, 다음 절차로 즉시 삭제할 수 있습니다.

1. **Mochi Jump 앱 실행**
2. 홈 화면 → **⚙ 설정** 아이콘 탭
3. 하단 **"계정 삭제"** 버튼 탭
4. 2단계 확인 다이얼로그에서 **"삭제"** 탭

처리 시간: 즉시 (수 초 내 서버 반영).

## 2. 이메일로 삭제 요청 (앱 미설치자용)

앱을 사용할 수 없는 경우 다음 이메일로 요청해 주세요.

- **이메일**: `hello@tovinlabs.com`
- **제목**: `[Mochi Jump] 계정 삭제 요청`
- **본문에 포함**:
  - 가입 시 사용하신 이메일 주소
  - 친구 코드 (8자리, 알고 계신다면)
  - 닉네임 (알고 계신다면)

처리 시간: 영업일 기준 **최대 7일 내** 회신 + 삭제.

## 3. 삭제되는 데이터

다음 정보가 **완전히 삭제**됩니다:

- 이메일 주소 / 닉네임 / 친구 코드
- 게임 진행도 (코인, 캐릭터 보유, 인벤토리, 베스트 점수)
- 친구 관계 / 우편함 / 채팅 기록
- 대표 모치 / 나만의 모치 / 꾸미기 설정
- 일일 보상 / 출석 기록
- 광고 식별자 매핑

## 4. 보존되는 데이터 (익명화)

법률 또는 운영 의무에 따라 다음 정보는 **개인 식별이 불가능한 익명 형태**로 보존됩니다:

- **게임 통계 집계** (전체 점수 분포, 캐릭터 사용률 등) — 개인 식별자 제거 후 통계 목적
- **신고 / 어뷰징 기록** — 안전한 게임 환경 유지 목적, 최대 1년
- **결제 / 광고 수익 정산 기록** — 회계법 의무, 최대 5년 (해당되는 경우)
