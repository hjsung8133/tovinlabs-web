# Account & Data Deletion — Mochi Jump

> Last updated: 2026-05-13

You can request the deletion of your Mochi Jump account and associated data.

## 1. Delete in-app (recommended, instant)

If the app is installed and you are signed in:

1. Open **Mochi Jump**
2. Home → tap the **⚙ Settings** icon
3. Tap **"Delete Account"** at the bottom
4. Confirm in the two-step dialog by tapping **"Delete"**

Processing time: instant (server reflects within a few seconds).

## 2. Email request (if you cannot use the app)

If the app is no longer accessible, send a request to:

- **Email**: `hello@tovinlabs.com`
- **Subject**: `[Mochi Jump] Account deletion request`
- **Please include**:
  - Email address used at signup
  - Friend code (8 digits, if known)
  - Display name (if known)

Processing time: within **7 business days**.

## 3. Data that will be fully deleted

- Email address / display name / friend code
- Game progress (coins, characters, inventory, best score)
- Friend relationships / mailbox / chat history
- Representative Mochi / My Mochi / decorations
- Daily rewards / attendance records
- Advertising ID mapping

## 4. Data retained (anonymized)

Due to legal or operational obligations, the following data is retained in an **anonymized, non-identifiable** form:

- **Game analytics aggregates** (score distribution, character usage) — anonymized for statistics
- **Abuse / report records** — for safe game environment, retained up to 1 year
- **Payment / ad revenue records** — accounting law, retained up to 5 years (if applicable)
